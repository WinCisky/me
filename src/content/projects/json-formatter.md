Paste raw JSON, get it pretty-printed, collapsible and validated. Built after one
too many API responses dumped on a single unreadable line.

## Highlights

- Streaming-friendly parser so large payloads do not freeze the tab
- Collapsible tree with keyboard navigation
- Everything runs client-side
