The site you're looking at. It's a small Astro app that renders server-side on
Deno Deploy. It lists my public GitHub repositories and pairs each one with
optional hand-written notes, an icon and a preview image. The UI borrows from a
desktop file browser, with recent files, a projects folder and an about page.
